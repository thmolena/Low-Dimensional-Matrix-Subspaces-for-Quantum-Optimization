# Configurations

The registered study parameters are defined in
`src/hqml_observable_subspaces/authentic_study.py`: eight Gset instances,
ten-vertex deterministic neighborhoods, depth one, anchor angles 0.55 and
0.32, task strengths 0.4 and 0.8, ranks 2, 4, and 6, and fixed random-baseline
seeds. Test tasks do not determine a method, rank, threshold, or seed.
